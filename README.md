# Distinct Shoot — Photography Website

A cinematic, class-forward photography portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + CSS Variables
- **Theming**: `next-themes` (dark/light mode)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Cormorant Garamond (display) + DM Sans (body)

## Design System
- **Display Font**: Cormorant Garamond (serif, elegant)
- **Body Font**: DM Sans (clean, lightweight)
- **Accent Color**: Gold `#C9A84C`
- **Light BG**: Cream `#FDFAF5`
- **Dark BG**: Obsidian `#0A0A0A`

## Pages
| Page | Route |
|------|-------|
| Home | `/` |
| Portfolio | `/portfolio` |
| About | `/about` |
| Services & Pricing | `/services` |
| Blog / Journal | `/blog` |
| Contact | `/contact` |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
